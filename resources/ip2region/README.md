数据字段为 `国家或地区|省份|城市|运营商|国家代码`。查询依赖 `py-ip2region==3.0.4`。

此目录不在公开静态资源路由下。查询不会向第三方发送 IP，也不使用外部在线查询接口。两个数据库合计约 48 MB；服务进程按需加载对应 IP 版本的数据库并缓存结果。

这是当前离线库对历史 IP 的推断，并非答题当时的精确位置。IP 可能来自网关、代理或移动网络；运营商字段中的云服务名称仅用于提示部分可识别的云出口，不能保证识别所有代理。不能将城市不同自动判为冒领，也不能以城市相同证明身份。
